# Waterbell Lab ver2.2：液滴中心の自動追跡

## 起動と公開
- 開発フォルダでは `index-v22.html` をChromeで開いてください。ver2.1は `index-v2-keyboard.html` に残っています。
- 公開用の一式は `github_upload_v22` フォルダにまとめています。このフォルダの中身をGitHubリポジトリの同じ階層へ配置すると、入口は `index.html` です。
- 必要な8ファイル：`index.html`, `app-v2.js`, `math-v2.js`, `style-v2.css`, `auto-contour-v2.js`, `keyboard-v2.js`, `auto-track-v22.js`, `tracking-ui-v22.js`。新機能もすべて端末内で処理し、画像を外部へ送信しません。

## 液滴中心を自動追跡する
1. 連続画像を読み込みます。円盤校正とベル形状・輪郭の指定はこれまでと同じです。
2. 液滴が独立して見える最初のコマへ移動し、「開始コマの液滴中心をクリック」で液滴中心を手動指定します。矢印キーでの微調整も可能です。
3. 「① 現在の中心を開始点に」を押します。
4. Alt＋左右矢印などで最後の**衝突前**コマへ移動し、「② 現在を追跡終了コマに」を押します。衝突後まで追わせないでください。
5. 「③ 自動追跡する」。次コマの予測位置周辺から、同じ液滴と思われる暗い小領域を探します。明暗差に重みをつけた重心を中心候補とします。開始点の座標もこの方法で再推定するため、最初のクリックから少し動く場合があります。
6. 表の「表示」で各コマに移動し、水色の丸が液滴中心にあるか拡大して確認します。類似度は開始点の画像とどの程度似ているかという指標で、正解率ではありません。
7. 採用しない候補のチェックを外し、「④ チェックした候補を採用」。採用前は従来の測定点や計算値を変更しません。既存点に重なるコマは置換確認が出ます。
8. 採用後、従来のクリックや矢印キーで修正・不足コマを追加できます。少なくとも3点が回帰に必要です。候補が1〜2点でも手動点と組み合わせられます。

チェックを外したコマや追跡範囲外の既存点は保持します。衝突後の既存点がある場合は、従来の追跡表で除外または削除してください。開始点を移動した場合は再登録してください。画像群の変更・次のイベント操作では開始点と候補をクリアしますが、保存済み結果行は従来通り残ります。

## 設定と限界
- 初期値は液滴の概略半径5 px、探索半径12 px、背景との明暗差35（輝度0〜255）です。画像上のサイズに合わせて変更してください。
- 明るい背景に写る暗い液滴を想定します。暗い背景や、白く光る液滴は対象外です。
- 色の濃い部分の連結領域を検出し、開始点と比べた大きさ・縦横寸法、画像パターンの相関、移動の連続性を使って候補を絞ります。
- 欠番、見失い、膜との重なり、似た候補が複数ある場合は途中で停止します。停止位置は衝突時刻の判定ではありません。誤認識を完全には防げないため、全候補を目視確認してください。
- 大きく変形した液滴、ブレ、重なり、急な移動には対応できない場合があります。検索幅を広げるほど別の液滴を拾う危険も増えます。
- サンプル画像のデフォルト設定では1289〜1291の3コマを追跡し、1292で停止します。1292以降を無理に補間・外挿して追跡点として追加しません。必要なコマは目視で手動指定してください。
- 検出重心と幾何学的な液滴中心は必ずしも一致しません。像の濃淡・ブレ・ハイライトで偏ります。小数座標は計算結果であり、サブピクセル精度の保証ではありません。
- CSVの19列は従来通り。notesに自動候補由来のコマ番号を記録します。手修正される可能性も明記しています。

## 外挿上限：初期値を5コマ先へ変更
ver2.1とver2.2の初期値は5/240秒＝約20.83 msです。欄の単位は従来どおりmsです。これは**最後に回帰へ使用した追跡点から先に交点を探す時間**で、自動追跡の終了コマ設定とは別です。追跡が早めに停止した場合は、必要に応じて衝突直前の点を手動追加してください。

## 「5 衝突と保存」の基本操作
自動の衝突交点が画像と合っているか確認し、「結果」の目視分類とメモを入力して「結果を1行追加」を押します。これで1件を画面内へ保存します。「CSVダウンロード」で全件をファイルに保存できます。ページを閉じる・再読込する前にダウンロードしてください。交点が合わないときだけ手動衝突点指定を使い、「軌道交点に戻す」で手動指定を解除できます。
